# Test scenarios

| Сценарий | Действие | Ожидаемый результат |
| --- | --- | --- |
| Создание заявки | Инициатор отправляет валидную заявку на закупку | Выбран маршрут снабжения, создана рабочая задача |
| Передача в финансы | Снабжение переводит счёт в статус «готов к согласованию» | Создана одна связанная финансовая задача, переданы нужные поля |
| Повторный webhook | Система повторно присылает то же событие | Новая задача и второе уведомление не создаются |
| Некорректное событие | В payload нет обязательного поля | Событие отклонено, бизнес-статус не меняется |
| Уведомление | Создана связанная задача | Уведомление адресовано только участникам нужного контекста |

Проверка проводилась сначала в тестовом контуре, затем — как контрольный прогон перед переносом настроек в рабочий контур.
